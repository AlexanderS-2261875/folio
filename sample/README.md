# Folio

A **clean**, native Markdown reader for macOS — *quietly* typeset, with ~~no clutter~~ live reload.

![Folio icon](icon.png)

## Features

- GitHub-flavoured Markdown: tables, task lists, strikethrough
- Outline sidebar built from your headings
- Live reload when the file changes on disk
- Follows light and dark mode
